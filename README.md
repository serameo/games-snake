# Snake Adventure

A complete Snake game written in Python and pygame, built in five
phases as a learn-by-doing project. It ships with a level editor, an
optional sprite system, generated sound effects, and a one-file
Windows build.

![status](https://img.shields.io/badge/status-complete-brightgreen)
![python](https://img.shields.io/badge/python-3.8%2B-blue)

## Features

- Smooth grid based snake movement with a queued input buffer
- Maps stored as plain text files that anyone can edit
- Wrap-around mode, per-map speed, targets, and lives
- Level menu, lives system, bonus scoring, persistent high scores
- Optional PNG sprites with automatic vector fallback
- Sound effects and music generated by a script, no downloads needed
- In-game mouse driven level editor with instant test play
- Single `.exe` build that runs without Python installed

## Quick Start

```powershell
git clone <your-repo-url>
cd snake_game
pip install pygame
python tools\make_sounds.py
python main.py
```

Python 3.8 or newer. Pygame 2.0 or newer.

## Architecture

| Layer        | Modules                              | Imports pygame |
|--------------|--------------------------------------|----------------|
| Logic        | `engine.py`, `level.py`, `scores.py` | No             |
| Presentation | `render.py`, `assets.py`, `audio.py` | Yes            |
| Control      | `main.py`, `editor.py`               | Yes            |
| Support      | `config.py`, `paths.py`              | No             |

`engine.py` never imports pygame. It advances the game by one step and
returns an event string, which keeps the rules testable from a plain
Python prompt:

```python
from engine import GameEngine
import level

game = GameEngine(level.fallback_level())
print(game.step())   # "none", "eat", "hit", "clear" or "gameover"
```

Those same event names double as sound file names, so `main.py` plays
audio with a single line and no lookup table.

## Running the Tests

```powershell
python -m unittest discover -s tests -v
```

24 tests cover movement, eating, collisions, the lives cycle, map file
round tripping, and the rule that `engine.py` never imports pygame.
They run in under a second because no window is ever opened.

## Map File Format

```text
@name Garden Maze
@speed 7
@dir right
@target 8
@lives 3
@wrap on

####################
#........#.........#
#..S..o..#....o....#
#........#.........#
####################
```

| Directive | Meaning                          | Default |
|-----------|----------------------------------|---------|
| `@name`   | Shown in the menu                | file name |
| `@speed`  | Cells per second at the start    | 6       |
| `@dir`    | `up` `down` `left` `right`       | right   |
| `@target` | Fruit needed to clear the level  | 5       |
| `@lives`  | Lives for this map               | 3       |
| `@wrap`   | `on` lets the snake cross edges  | off     |

| Symbol | Meaning     |
|--------|-------------|
| `.`    | Open floor  |
| `#`    | Wall        |
| `o`    | Fruit spawn |
| `S`    | Snake start |

Every map needs exactly one `S`. Rows may be different lengths; short
rows are padded with open floor. A broken file never crashes the game:
it appears in the menu marked `[ERROR]` with the reason in the HUD.

## Custom Art and Sound

Everything below is optional. Missing files fall back to built-in
vector drawing and silence.

| Drop into `assets/images/` | Replaces                        |
|----------------------------|---------------------------------|
| `head.png`                 | Snake head, draw it facing right |
| `body.png`                 | Body segment                    |
| `tail.png`                 | Tail segment                    |
| `fruit.png`                | Fruit                           |
| `wall.png`                 | Wall block                      |

Use square PNGs with transparency, 64 x 64 or larger. They are scaled
once at startup, so any size works.

| Drop into `assets/sounds/` | Plays when              |
|----------------------------|-------------------------|
| `eat.wav`                  | Fruit collected         |
| `hit.wav`                  | A life is lost          |
| `clear.wav`                | Level cleared           |
| `gameover.wav`             | Last life lost          |
| `menu.wav`                 | Menu navigation         |
| `music.ogg` / `.wav`       | Background loop         |

To regenerate the default sounds, or to change the melody, edit the
`melody` list at the bottom of `tools/make_sounds.py` and run it again.

## Building the Executable

```powershell
pip install pyinstaller
python tools\make_sounds.py
python build.py --clean
```

The result is `dist\SnakeAdventure.exe`, roughly 25 to 40 MB. Copy that
single file anywhere. On first run it creates a `SnakeAdventure` folder
beside itself:

```text
C:\Games\
??? SnakeAdventure.exe
??? SnakeAdventure\
    ??? levels\      factory maps plus anything you draw
    ??? scores.json  high scores
```

Delete that folder to reset the game to its factory state.

| Build issue                | Fix                                        |
|----------------------------|--------------------------------------------|
| Antivirus warning          | Expected for unsigned PyInstaller output   |
| No sound in the exe        | Run `tools\make_sounds.py` before building |
| Maps missing               | The `levels` folder was empty at build time |
| Slow first launch          | Switch the spec to `--onedir`              |

## Tuning the Game

Almost every number lives in `config.py`, so behaviour can be changed
without reading any other file.

| Setting            | Effect                                  |
|--------------------|-----------------------------------------|
| `CELL_SIZE`        | Size of one grid square in pixels        |
| `START_SPEED`      | Cells per second at the start of a map   |
| `SPEED_STEP`       | Speed added per fruit eaten              |
| `MAX_SPEED`        | Upper limit so the game stays fair       |
| `START_LIVES`      | Lives when a run begins                  |
| `DEFAULT_TARGET`   | Fruit needed when a map omits `@target`  |
| `RESPAWN_DELAY`    | Pause length after losing a life         |
| `SFX_VOLUME`       | Sound effect loudness, 0.0 to 1.0        |
| `MUSIC_VOLUME`     | Music loudness, 0.0 to 1.0               |

## Ideas for Extending

Roughly in order of difficulty:

1. New fruit types with different point values
2. A golden fruit that disappears after a few seconds
3. Moving hazards that patrol a fixed route
4. Teleport tiles that pair up across the map
5. Two player split screen on one keyboard
6. Sharing maps by exchanging text files
